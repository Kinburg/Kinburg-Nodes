Image Compare — help

Compare a set of images side by side and review them. Click any image to open it full-screen (← → to browse, Esc to close).

Comparison modes — keys 1…5

  • Grid (1) — every image at once.
  • Slider (2) — drag the divider to wipe between the A and B images.
  • Opacity (3) — fade B over A with the slider that appears just above the image.
  • Flip (4) — toggle A↔B in place (click, Space, or ← →) to spot small changes; the plate on the image tells you which one you're looking at.
  • Difference (5) — per-pixel difference of A and B; darker = more identical.

The header reads left to right by purpose: modes pinned left, the viewing controls (👁 Panels, Zoom, ⤢ Fit, 🔍 Loupe) centred, and ⬇ Save page / 📊 Report / ❔ Help pinned right. Its last row always belongs to the current mode: Columns / Rows / Sort in Grid, and the A / B selectors in the pair modes — where they meet at the centre of the page, on the same seam the wipe divider sits on, so each one is on the side of the image it controls.

Zoom & pan — synced across every image

The Zoom slider magnifies all images at once, and they all show the same region: drag any one of them and the visible area moves in every image together. Made for comparing fine detail — texture, small faces, fabric, foliage — without hunting for the same spot in each picture.

  • Drag any image (once zoomed) — pans them all.
  • Ctrl + wheel over an image — zooms at the cursor, so the bit you point at stays put.
  • Double-click, 0, or ⤢ Fit — back to fit.
  • The region is kept in relative coordinates, so it holds when you switch modes, change Columns / Rows, or compare images of different sizes.

In Slider mode while zoomed, drag the divider's round handle to move the wipe (dragging the picture pans instead). Reordering keeps working at any zoom — it goes through each card's ⠿ grip.

Loupe (magnifier)

Turn on 🔍 Loupe and hover an image to magnify it — it works in every mode (in Slider/Opacity/Difference it magnifies both A and B with the same blend; in Grid it's synced across all images). Wheel = lens zoom, Alt/Shift + wheel = lens size.

It stacks on top of Zoom: the lens shows zoom × lens while everything around it stays at the current zoom, so you can hold every image on a region and then peek closer still. Ctrl + wheel is always the image zoom, even with the lens on, and dragging still pans.

Panels & review

👁 Panels holds what's shown under each image — Captions, Prompts, Settings, Time, Metrics, 🤖 Judge — plus Hidden, which lists the results you rejected (a badge on the button counts them). The menu stays open while you flip several. In Grid you also set Columns, Rows and Sort, and can reorder cards in “Original order” by dragging the ⠿ grip in a card's top-left corner — everything else on the card, including the prompt and settings text, stays selectable.

Rows on screen

Rows is how many rows of results you want to see at once, and the image height follows from it — at 1 (the default) one row fills the window, and scrolling snaps row by row, so the page behaves like a flipper: one comparison at a time, always the same size. It adapts by itself when you toggle a panel or change Columns, and never asks for more rows than there actually are.

Each card gives the picture whatever its panels leave over, so a card with a long prompt shows a slightly smaller image than its neighbour; if the panels would crowd the picture out altogether they scroll inside the card instead. Set Rows to 0 when you'd rather fix the height yourself — Max h (px) then takes over, and it's what you want for comparing at a specific scale.

Each image has your own review: a ★ rating, tags, a comment, and a ✕ hide/reject — all saved in this browser, so they survive reloads.

Similarity metrics — SSIM & PSNR

Shown only when a reference image was provided on the node. They measure how close each image is to the reference — not how good it looks.

  • PSNR (dB) — pixel-level difference. Higher = more similar; ∞ = identical. Rough guide: >40 near-identical, 30–40 minor differences, <25 clearly different.
  • SSIM (0–1) — structural similarity (luminance, contrast, structure), closer to how the eye judges likeness. 1 = identical; >0.98 ≈ imperceptible, 0.9–0.98 slight, <0.8 different.

Sort by Similarity to rank closest→farthest. Handy for upscaling, img2img and restoration, or for checking how far a quantized model drifts from its baseline.

🤖 Judge

When a Vision LLM Judge is connected, each image shows the AI's read-only verdict — stars, tags and a comment — kept separate from your own review. In multi-criteria mode it also lists a coloured per-criterion score chip (e.g. anatomy 4/5), and the Sort menu gains Judge score ↓ plus a Judge: <criterion> ↓ entry for each criterion.

Report & saving
